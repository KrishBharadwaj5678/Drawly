<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Drawly/raw/main/favicon_io/favicon.ico" width="40"/> Drawly</h1>

<p align="center">
  Drawlyは、アイデアを正確かつ簡単に作成・視覚化できるよう設計されたWebベースの描画プラットフォームです
</p>

## <img src="https://github.com/KrishBharadwaj5678/Drawly/raw/main/src/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
| ---- | ---- |
| ✍️ **フリーハンド描画** | 滑らかで自然な線を正確に描画できます |
| 🔷 **図形とツール** | 長方形、円、矢印などのさまざまな図形を使用できます |
| ↩️ **元に戻す/やり直す** | 操作を簡単に取り消したり、以前の状態に戻したりできます |
| 🖍️ **カスタマイズ可能な色** | 豊富なカラーパレットから色を選択して描画をカスタマイズできます |
| 💾 **エクスポート** | 作成した描画を簡単に保存できます |
| 🖥️ **Webベース** | ブラウザを使用して、さまざまなデバイスからアクセスできます |

## <img src="https://github.com/KrishBharadwaj5678/Drawly/raw/main/src/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Drawly.git
```

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd Drawly
```

### 3️⃣ 依存関係をインストール

```bash
npm install
```

### 4️⃣ 開発サーバーを起動

```bash
npm run dev
```
