<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Drawly/raw/main/favicon_io/favicon.ico" width="40"/> Drawly</h1>

<p align="center">
  Drawly é uma plataforma de desenho baseada na web, projetada para ajudar os usuários a criar e visualizar ideias com precisão e facilidade
</p>

## <img src="https://github.com/KrishBharadwaj5678/Drawly/raw/main/src/assets/readme/features.gif" width="35"/> Recursos

| Recurso | Descrição |
| ------- | --------- |
| ✍️ **Desenho à Mão Livre** | Crie linhas suaves e naturais com precisão |
| 🔷 **Formas e Ferramentas** | Utilize formas prontas, como retângulos, círculos, setas e muito mais |
| ↩️ **Desfazer/Refazer** | Corrija erros facilmente ou retorne a alterações anteriores |
| 🖍️ **Cores Personalizáveis** | Escolha cores de uma paleta vibrante para aprimorar seus desenhos |
| 💾 **Exportação** | Salve seus desenhos de forma rápida e fácil |
| 🖥️ **Baseado na Web** | Acesse a aplicação de qualquer dispositivo com um navegador |

## <img src="https://github.com/KrishBharadwaj5678/Drawly/raw/main/src/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Drawly.git
```

### 2️⃣ Acesse o diretório do projeto

```bash
cd Drawly
```

### 3️⃣ Instale as dependências

```bash
npm install
```

### 4️⃣ Inicie o servidor de desenvolvimento

```bash
npm run dev
```
