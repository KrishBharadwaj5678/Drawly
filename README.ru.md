<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Drawly/raw/main/favicon_io/favicon.ico" width="40"/> Drawly</h1>

<p align="center">
  Drawly это веб-платформа для рисования, созданная для того, чтобы пользователи могли легко и точно создавать и визуализировать свои идеи
</p>

## <img src="https://github.com/KrishBharadwaj5678/Drawly/raw/main/src/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| ----------- | -------- |
| ✍️ **Свободное рисование** | Создавайте плавные и естественные линии с высокой точностью |
| 🔷 **Фигуры и инструменты** | Используйте готовые фигуры, такие как прямоугольники, круги, стрелки и другие элементы |
| ↩️ **Отмена/Повтор** | Легко отменяйте действия и возвращайтесь к предыдущим изменениям |
| 🖍️ **Настраиваемые цвета** | Выбирайте подходящие цвета из доступной палитры для оформления рисунков |
| 💾 **Экспорт** | Легко сохраняйте созданные рисунки |
| 🖥️ **Веб-приложение** | Используйте Drawly с любого устройства через веб-браузер |

## <img src="https://github.com/KrishBharadwaj5678/Drawly/raw/main/src/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/Drawly.git
```

2️⃣ Переход в директорию проекта

```bash
cd Drawly
```

3️⃣ Установка зависимостей

```bash
npm install
```

4️⃣ Запуск сервера разработки

```bash
npm run dev
```
